# 기한노트 — 업무 기한 계산기

AI 리더스 아카데미 바이브코딩 과제 (예시 2).

시작일과 기간을 입력하면 달력 기준과 토·일 제외 근무일 기준의 마감일을 나란히 보여주는 웹앱입니다.

## 주요 기능
- 시작일 및 1~3,650일 기간 입력
- 달력/근무일 마감일 동시 계산
- 오늘 기준 D-day
- 3일, 7일, 14일, 30일 빠른 선택
- 결과 복사 및 모바일 대응

## 계산 기준
시작일은 제외하고 다음 날부터 계산합니다. 근무일은 월~금이며 공휴일은 별도로 제외하지 않습니다.

## 실행
index.html 하나에 화면과 기능이 모두 포함되어 있습니다. 파일을 브라우저에서 열면 바로 실행됩니다.

## Vercel 배포
저장소를 Import하고 Framework Preset은 Other, 빌드 명령은 비우고 기본 출력 폴더를 사용합니다. 환경변수나 데이터베이스는 필요하지 않습니다.

## 검증
주말 시작, 금요일 마감, 연말, 윤년, 입력 오류 등 날짜 계산 검증과 브라우저 동작 확인을 완료했습니다.
